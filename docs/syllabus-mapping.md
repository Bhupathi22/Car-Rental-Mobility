### Verification and Demonstration Checklist for Faculty Reviewers

1. **Database Persistence**: Register a customer, add a car as admin, check MongoDB to confirm real document creation.
2. **OpenFreeMap Integration**: Open car details or live tracking to observe MapLibre GL rendering with OpenFreeMap vector liberty tiles (no Google Maps API key required).
3. **Cryptographic QR Check-in**: Book a car, click **View QR**, and simulate scanning at `/verify-booking/:id` to inspect the 4-point verification checklist.
4. **Interactive Dashboard**: Log in as `admin@mobility.com` to inspect aggregated revenue, fleet availability, and user charts computed via MongoDB Aggregation Pipelines.
5. **Testing Suite**: Execute `npm test` inside `backend/` to run all 12 Jest/Supertest integration suites.
